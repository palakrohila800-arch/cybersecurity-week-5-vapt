# Cybersecurity Week 5 – VAPT Practical

## Objective
To perform basic Vulnerability Assessment and Penetration Testing in an authorized lab environment.

## Tools Used
- Nmap
- Nikto
- Burp Suite

## Practical Work
- Nmap SYN scan
- Nmap service/version detection
- Nmap aggressive scan
- HTTP/HTTPS port checking
- Nikto target connectivity testing
- Burp Suite target testing

## Findings / Observations
- Target host was reachable, but HTTP/HTTPS ports were filtered.
- Service/version information could not be obtained because of filtered ports.
- Nikto and Burp Suite could not establish a connection with the target.

Screenshots of the practical activities are uploaded in this repository.

## Conclusion
The practical helped in understanding basic VAPT methodology, network scanning, service detection, and security testing limitations.
